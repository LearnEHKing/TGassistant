# TGassistant
A personal Telegram assistant using Python-Telegram-bot.

#Setup:
• Run ```bash setup.sh```
• Install required packages if not installed by setup.sh.
• Paste Telegram API Token and ID of owner inside ```Data/config.json```.
• Run ```python main.py```

# Uses
I am your personal assistant. Made for just you. I'll do these things for you: 
• Greet with GM and GN.
• Send a joke daily.
• Remind you about your period date.
• Listen to you, when noone is listining to you.
